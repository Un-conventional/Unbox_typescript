Frequently Asked Questions

Read first! What is Unbox? (See below)
  • This is UltraBox but with my ideas added on. This also is sort of a testing ground for me to learn code.
  • Some ideas come from how sound chips work and that and many ideas may seem excessive but pushing limits is fun.
  • This mod is for anyone regardless of skill level, I strongly suggest checking out UltraBox first though.
  • Why does it exist? - It exists because I wanted it to exist. I got tired of asking "what if X existed" or "why can't W, X, Y apply to Z as well".
  • Why is the b in Unbox not a capitalized B? Why is it not called UnBox or UNBox? Because I said so and I found it weird having it spelled that way.
    • How does Unbox differ from UltraBox? The current features include:

    ± 24 Pitch Shift Range

    • I felt the range was too small so I increased it. It still works the same as normal Pitch Shift but with more range.

    0%-100% Pulse Width Range

    • The fact that 1%-50% just felt limiting. With what I added, 0-100% is possible if you include the decimal offset. There is just so much that is possible with that range increase

    Several new chip waves and presets

    • The new "chip" chipwaves/presets mimic what exists on chips - These are a work in progress! Feedback is requested to make these better.
    • The new Presets that arent chip mostly consist of instruments I like and a few have sentimental value. These are also work in progress!

    Increased max tempo to 1000

    • Ever wanted to make songs that are faster than 500 "tempo"? For "Pseudo Overclock" that would limit you to about 200Hz. I increased it to 1000 so 400Hz "Pseudo Overclock" should be available. I would like to increase it to 10k at one point for 1kHz.
    • I also added new rhythms that should help out if you increase the beats per bar in tandem with higher tempo. You still can edit the tempo via the text box regardless.

    Set playerhead to start of loop

    • How many times did you want to jump to the start of the loop? All the time? Yeah, that is why I made this shortcut. It even was put in UltraBox!

    Three new themes, Classic and Legacy and Glow.

    • Classic is the default theme, I think its nice.
    • Legacy is the original theme but it has issues but I still like it.
    • Glow is something I wanted to try with transparent stuff. I like it.

    What happened to Duty Cycle?

    • This has been replaced with a Sequence/Macro system.
    • This new system won't be limited to just Duty Cycle
    • I wanted to revive a function from an old mod called SandBox and that mod had Duty Cycle but it was limited to a few pulse widths and only 2 cycle types.
    • However, this system will improve it and allow other functions as stated below.

    Sequence Editor

    • This replaced "Duty Cycle" and improved upon the original idea I had for it.
    • It has a layout similar to trackers so if you know trackers, you probably know how to use this.
    What features are planned? I cannot guarantee anything but what is likely to be added are as follows.

    Macro/Sequence

    Ring Modulation (AB)

    How do I add custom samples? Since Unbox doesn't have a web server of its own, you'll have to first upload your sample to a CORS-friendly website.
    • The easiest to use is File Garden.
    Next, you have to copy the URL of the sound itself. The URL should end with the filetype, such as .wav or .mp3.

    To import it into Unbox, open the Edit tab, scroll to the bottom, and click on "Add Custom Samples..."

    Paste your url and press "Okay." If everything goes smoothly, Unbox will reload and your sample will be available in the preset list.
    Does Unbox have an offline version? NO!, Not yet but you can access UltraBox's here.
    You can either download an OS-specific version that has custom sampling support, or the generic HTML version that lacks custom sampling support.

All song data is contained in the URL after the hash (#) mark, and Unbox running inside your browser converts that data into sound waves.

    Chipwaves

    VRC6 Sawtooth?

    • This is a new more accurate one and includes the "HI" varaint.

    Buzzer?

    • Logarithmic Triangle and Sawtooth waves with a distinct sound most notably from the AY-3 and YM2149 sound chips. Obelisco is the Furnace name for this and the old variant of this has this name.

    ST TImer?

    • This mimics A timer Effect often used on the Atari ST (YM 2149f based system).

      Don't ask for the Revision number and keep in mind, IRL two "identical" SID chips may sound drastically different from each other, even with the same revision.

    • Sawpulse - 6581 and 8580 style
    • Trisaw - 6581 and 8580 style
    • Trisawpulse - 6581 and 8580 style
